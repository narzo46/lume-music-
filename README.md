# SoundNest

Локальный музыкальный плеер для Android.

Что есть:
- импорт музыки из системы
- локальный офлайн плеер
- список треков
- поиск по библиотеке
- play/pause, next/previous
- темный Spotify-like интерфейс

Сборка:
1. Открой в Android Studio
2. Синхронизируй Gradle
3. Build -> Build APK(s)

Собранный APK будет в app/build/outputs/apk/debug/
